# 📌 Overview

Traveloop is a premium full-stack travel planning platform built to transform the way users organize and experience travel.

Inspired by high-end travel editorials and cinematic destination storytelling, Traveloop combines immersive visuals with practical trip-management tools to create an experience that feels both aspirational and functional.

The platform enables users to:

* 🗺️ Build personalized multi-city itineraries
* 🌆 Add both predefined and custom cities
* 🎯 Create custom travel activities
* 💰 Manage overall and per-trip budgets
* 📝 Quickly access notes, equipment lists, and essentials
* 📅 Organize complete travel timelines
* 🎒 Manage packing & equipment checklists
* 🔗 Share journeys publicly
* 📊 Visualize travel expenses and insights

The overall design language follows a:

* 🌿 Premium emerald-green aesthetic
* 📰 Editorial travel magazine feel
* ✨ Glassy layered interface system
* 🧭 Cinematic and immersive dashboard experience
* 🪄 Dynamic layouts with soft modern interactions

Traveloop is designed to make trip planning feel as exciting as the journey itself.

# 🚀 Getting Started

# 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/traveloop.git
```

```bash
cd traveloop
```

---

# 2️⃣ Install Dependencies

```bash
npm install
```

---

# 3️⃣ Configure Environment Variables

Create a `.env` file in the root directory.

```env
DATABASE_URL=
DIRECT_URL=
AUTH_SECRET=
NEXTAUTH_URL=http://localhost:3000
```

---

# 4️⃣ Setup Prisma Database

```bash
npx prisma migrate dev
```

---

# 5️⃣ Seed Database

```bash
npm run prisma db seed
```

OR

```bash
npx prisma db seed
```

---

# 6️⃣ Run Development Server

```bash
npm run dev
```

Open:

```txt
http://localhost:3000
```

---

# 🚀 Local Setup

```bash
git clone https://github.com/your-username/traveloop.git
cd traveloop
npm install
npm run dev
```

Create a `.env` file:

```env
DATABASE_URL=
AUTH_SECRET=
NEXTAUTH_URL=http://localhost:3000
```
